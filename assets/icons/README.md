# Technology icon sources

The 16 SVG files in this directory are vendored from Simple Icons:
https://github.com/simple-icons/simple-icons/tree/develop/icons

Retrieved 15 November 2026. Upstream CC0 1.0 Universal text is retained in
LICENSE.md. Filenames match the upstream icon slugs. Artwork is bundled locally;
the README makes no requests to an icon service.

`tools/build_assets.py` embeds these paths into the desktop and mobile toolkit
panels with a coordinated ice-blue fill. SQL and VS Code use clearly labeled
neutral DB/VS monograms, rather than invented technology logos.

To update a source icon, replace its SVG here and run the artwork generator.
